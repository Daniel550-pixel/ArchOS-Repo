# ArchOS Roadmap

ArchOS is under active development. This roadmap describes direction, not guaranteed delivery dates.

## Stage 1 — Open-source foundation

- [x] Public repository
- [x] MIT license
- [x] Contribution guidelines
- [x] Security policy
- [x] Code of conduct
- [x] Pull-request and issue templates
- [x] Architecture documentation

## Stage 2 — Engineering baseline

- [ ] Establish a reproducible local development environment across supported platforms
- [ ] Define supported Node.js/Python/runtime versions
- [ ] Expand automated unit and integration coverage
- [ ] Establish deterministic CI gates for critical backend and frontend paths
- [ ] Add dependency and security scanning
- [ ] Document configuration and secret-management requirements

## Stage 3 — AIOS/JARVIS runtime

- [ ] Stabilize orchestration interfaces
- [ ] Formalize agent capability contracts
- [ ] Strengthen action-gating and authorization boundaries
- [ ] Improve agent observability and execution tracing
- [ ] Establish reliable memory/state boundaries

## Stage 4 — World model and intelligence

- [ ] Stabilize world-model data contracts
- [ ] Expand causal and scenario reasoning
- [ ] Improve simulation reproducibility
- [ ] Add stronger provenance and verification for intelligence outputs

## Stage 5 — Multimodal experience platform

- [ ] Expand reusable Experience Engine modules
- [ ] Improve voice, vision, and gesture interoperability
- [ ] Harden 3D rendering and resource lifecycle management
- [ ] Improve accessibility and reduced-motion behavior

## Stage 6 — Open-source ecosystem

- [ ] Publish contributor-oriented architecture documentation
- [ ] Grow external contributor participation organically
- [ ] Add examples and reusable modules
- [ ] Establish release/versioning policy
- [ ] Publish stable packages or APIs where appropriate

## What success means

The objective is not to make unverified claims about scale. Success means that ArchOS becomes a technically credible, secure, reproducible, well-documented open-source AI software platform that other developers can inspect, run, extend, and contribute to.
